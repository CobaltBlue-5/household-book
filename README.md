# 家計簿アプリ — 公開とセットアップの手順

スマホ（Android）専用の家計簿です。アプリ本体は GitHub Pages、カード明細の取り込みはあなたの Google アカウント上のスクリプトで動くので、Claude を解約してもそのまま使い続けられます。家計簿のデータはスマホの中だけに保存されます。

## フォルダの中身

| ファイル | 役割 |
|---|---|
| `index.html` `style.css` `app.js` | アプリ本体 |
| `sw.js` `manifest.webmanifest` `icons/` | オフライン動作とホーム画面アイコン |
| `art.jpg` | モンドリアンの作品（同梱済み） |
| `gas/Code.gs` | カード明細の取り込みスクリプト（GitHubには上げなくてOK、手順4で使う） |

---

## 1. モンドリアンの絵について

`art.jpg` には、モンドリアン「赤・青・黄のコンポジション II」（1930年）を同梱済みです。額縁を切り落として幅1000pxに縮め、ホームの縦長の区画では左寄り（白・青・黒線・赤が入る位置）で表示されるようにしてあります。モンドリアンは1944年没で、この作品の著作権は切れています。

別の絵にしたいときは、アプリの「設定 → アート → 画像を選ぶ」でスマホ内の画像に差し替えられます。

## 2. GitHub Pages で公開する

1. [github.com](https://github.com/) でアカウントを作る（無料）
2. 右上の「＋」→「New repository」。名前は `kakeibo` など、**Public** を選んで作成
3. 作成直後の画面で「uploading an existing file」をクリック
4. このフォルダの中身（`gas` フォルダ以外すべて。`icons` フォルダごと）をドラッグ＆ドロップ →「Commit changes」
5. リポジトリの「Settings」→ 左の「Pages」→ Branch を `main` / `/ (root)` にして「Save」
6. 1〜2分待つと、`https://（ユーザー名）.github.io/kakeibo/` でアプリが開けるようになります

リポジトリは公開されますが、入っているのはプログラムだけです。家計簿のデータやカードの情報は含まれません。

## 3. スマホにインストールする

1. Android の Chrome で上のURLを開く
2. 右上の「︙」→「ホーム画面に追加」または「アプリをインストール」
3. 以後はホーム画面のアイコンから起動。電波がなくても動きます

最初に「設定」で毎月の予算を入れておくと、ホームに残り予算が出ます。

## 4. カード明細の自動取り込み（三井住友カード）

Gmail に届く「ご利用のお知らせ」メールを読み取り、アプリを開くたびに新しい利用分を自動で取り込みます。

### 4-1. スクリプトを作る（PCでの作業がおすすめ）

1. [script.google.com](https://script.google.com/) を開き、利用通知が届く Gmail のアカウントでログイン →「新しいプロジェクト」
2. 最初から入っているコードを全部消して、`gas/Code.gs` の中身を貼り付ける
3. 7行目の `TOKEN` を、20文字以上の適当な英数字に書き換える（例：`k8Fq2mXr9TzL4wNc7Hs1`）。これが合言葉になります
4. 上部の関数選択で `test` を選び「▶ 実行」
   - 「承認が必要です」→ 自分のアカウントを選ぶ →「このアプリは Google で確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」→「許可」
   - 自分で作ったスクリプトなので問題ありません。Gmail を**読む**権限だけを使います
5. 下の実行ログに `"found":` と、`parsed` に利用日・店名・金額が出ていれば成功

### 4-2. アプリとつなぐ

1. 右上「デプロイ」→「新しいデプロイ」→ 歯車から「ウェブアプリ」
2. 「次のユーザーとして実行」＝**自分**、「アクセスできるユーザー」＝**全員** →「デプロイ」
3. 表示された「ウェブアプリのURL」をコピーし、末尾に `?token=（手順4-1-3の合言葉）` を付ける
   例：`https://script.google.com/macros/s/AKfy…/exec?token=k8Fq2mXr9TzL4wNc7Hs1`
4. そのURLをスマホに送り（自分宛てメールなど）、アプリの「設定 → カード明細の自動取り込み」に貼って「保存」

すぐに過去2か月分の利用が取り込まれます。このURLは合言葉入りなので、人に教えないでください。

### カテゴリ分けのしくみ

- コンビニ・スーパー・JR・ドラッグストアなど、よくある店名は自動でカテゴリ分けされます
- 判定できなかった店は「未分類」になり、ホームに「未分類 ○件」と出ます。タップして選ぶと**その店を覚えて**、次回からは自動で分類されます
- 取消の明細はマイナスの金額で入るので、合計は自動で正しくなります
- カードで払っている家賃やサブスクは、アプリの「固定費」に登録しないでください（二重になります）。固定費は現金・口座引き落としの分だけに

### うまく取り込めないとき

- アプリの設定画面にエラーが出ていれば、その内容を確認
- 「合言葉が一致しません」→ URL末尾の `?token=` とスクリプトの `TOKEN` が同じか確認
- 件数が0件のまま → スクリプトの `test` を実行してログを見る。`found: 0` なら Gmail に該当メールがないか、件名・差出人が違います。Gmail で実際の利用通知メールを開き、件名と差出人に合わせて `Code.gs` の `QUERY` を書き換えてください
- `parsed` が空 → メールの書式が想定と違います。ログの `head`（本文の冒頭）を見て調整が必要です
- スクリプトを書き換えたら「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン：新バージョン」→「デプロイ」（URLは変わりません）

## 5. バックアップ

データはスマホの中だけにあるので、Chrome の「閲覧データを削除」でサイトデータを消すと家計簿も消えます。

- 「設定 → バックアップ → 書き出す」で共有メニューが開くので、Googleドライブに保存
- 14日以上バックアップしていないと、ホームに知らせが出ます
- 機種変更やデータが消えたときは、新しいスマホでアプリを入れて「読み込む」でファイルを選ぶだけ。覚えた店の分類や、取り込み済みの明細の記録も戻ります（カード連携URLだけは入れ直してください）

## 6. あとから見た目や機能を変えるとき

GitHub のリポジトリでファイルを開き、鉛筆アイコンで編集 →「Commit changes」。変更したら `sw.js` の1行目 `kakeibo-v1` の数字を `v2`, `v3`… と上げておくと、スマホ側にも確実に反映されます（アプリを2回開き直すと切り替わります）。
